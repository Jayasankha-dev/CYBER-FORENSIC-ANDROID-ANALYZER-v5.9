# 📱 Android Forensic & Security Audit: Shell Command Reference

*Note: These commands are formatted for execution directly within an `adb shell` session.*

---

## 🔍 1. System Information & Environment Audit

Identify the target device's hardware, OS details, and security patch levels.

| Command | Description |
| --- | --- |
| `getprop ro.build.version.release` | Get the Android OS version. |
| `getprop ro.build.version.security_patch` | Check the last security patch date (Critical for exploit analysis). |
| `getprop ro.product.model` | Get the exact device model name. |
| `uptime` | See how long the device has been running since the last reboot. |
| `dumpsys battery` | View battery health, status, and voltage. |

---

## 🛡️ 2. Package & Malware Analysis

Search for hidden apps, stalkerware, and unauthorized installations.

| Command | Description |
| --- | --- |
| `pm list packages -3` | List all user-installed (3rd party) applications. |
| `pm list packages -s` | List all system applications. |
| `pm list packages -d` | List only disabled applications (Often used by malware to hide). |
| `pm path <package_name>` | Locate the physical path of an APK file on the storage. |
| `dumpsys package <package_name>` | Deep dive into an app: permissions, install source, and signatures. |
| `pm list permissions -g -u` | List all dangerous permissions requested by apps. |

---

## 🌐 3. Network Forensic Monitoring

Detect suspicious outbound connections, C2 (Command & Control) traffic, or open ports.

| Command | Description |
| --- | --- |
| `netstat -ant` | Show all active network connections (Look for "ESTABLISHED"). |
| `netstat -lnt` | Show all listening ports on the device. |
| `ip addr` | View the device's local IP address and network interfaces. |
| `dumpsys wifi` | Get detailed Wi-Fi logs, including saved SSIDs and MAC addresses. |

---

## 📂 4. File System & Storage Investigation

Crawl the file system for hidden payloads, logs, and encrypted databases.

| Command | Description |
| --- | --- |
| `ls -laR /sdcard/` | Recursively list all files including hidden ones (prefixed with `.`). |
| `find /sdcard/ -name "*.php" -o -name "*.sh"` | Search for web shells or malicious scripts in storage. |
| `ls -la /data/local/tmp` | Check the temp folder (Commonly used by hackers to execute binaries). |
| `df -h` | View partition usage (Look for unusually full system partitions). |

---

## 🕵️ 5. Live Evidence & Volatile Data

Extract data that changes frequently, such as logs, clipboard, and active processes.

| Command | Description |
| --- | --- |
| `logcat -v time -d` | Dump the system log buffer for analysis. |
| `dumpsys window | grep mCurrentFocus` | Identify the app currently active on the screen. |
| `top -n 1 -m 15` | View the top 15 CPU-consuming processes. |
| `dumpsys clipboard` | Extract current clipboard contents (`mText`). |
| `service call clipboard 2` | Raw retrieval of clipboard service data. |

---

## 📑 6. Database & PII Extraction (Personal Info)

Extract user data for forensic reporting.

| Command | Description |
| --- | --- |
| `content query --uri content://sms/` | Dump all SMS messages (Inbound/Outbound). |
| `content query --uri content://call_log/calls` | Extract full call history. |
| `content query --uri content://com.android.contacts/data` | Extract contact list and associated emails/numbers. |
| `screencap -p /sdcard/sc.png` | Capture a screenshot for evidence. |

---

## 🚀 7. Persistence & Auto-Start Investigation

Malware often requests permissions to auto-start after a reboot. Use these to find them.

| Command | Description |
| --- | --- |
| `dumpsys activity services` | List all currently running background services. |
| `dumpsys alarm` | Check scheduled tasks/alarms (Used by malware to "wake up"). |
| `cmd package list-broadcast-receivers` | List apps listening for `BOOT_COMPLETED` (Auto-start on boot). |
| `appops query-op RUN_IN_BACKGROUND allow` | List all apps allowed to run in the background. |

---

## 👤 8. User Account & Identity Forensics

Analyze registered accounts (Google, Facebook, etc.) and user profiles.

| Command | Description |
| --- | --- |
| `dumpsys account` | Show all registered accounts (Emails, Usernames) on the device. |
| `pm list users` | Check for multiple user profiles or hidden "Work Profiles." |
| `settings get secure android_id` | Get the unique Android ID of the device. |
| `dumpsys user` | Get detailed info about the primary user and privileges. |

---

## 🛰️ 9. Hardware & Sensor Forensics

Monitor the usage of hardware sensors like the camera, microphone, and GPS.

| Command | Description |
| --- | --- |
| `dumpsys sensor_service` | Check if any app is currently using sensors. |
| `dumpsys location` | View recent GPS/Location requests from apps. |
| `dumpsys media.camera` | See which app last accessed the camera. |
| `dumpsys audio` | View audio stream status (Check for active recording). |

---

## 🛠️ 10. Security Setting Audits

Verify if system security features have been tampered with or disabled.

| Command | Description |
| --- | --- |
| `settings get global adb_enabled` | Check if ADB is permanently enabled (Security risk). |
| `settings get secure install_non_market_apps` | Check if "Unknown Sources" is turned ON. |
| `settings get global development_settings_enabled` | See if Developer Options are active. |

---

## 🛑 11. Emergency & Incident Response

Quick actions to take when a compromise is detected.

| Command | Description |
| --- | --- |
| `pm disable-user <package_name>` | Instantly "Freeze" a suspicious app (Preserves evidence). |
| `pm clear <package_name>` | Wipe an app's data and cache immediately. |
| `pkill -f <process_name>` | Kill a process by its name. |

---

### 💡 Pro Tip: Filtering Data

Since shell outputs can be massive, always use `grep` to find exactly what you need.

* **Example:** Find the current active activity:
`dumpsys activity | grep "mResumedActivity"`
* **Example:** Check when a specific app was installed:
`dumpsys package <pkg_name> | grep "firstInstallTime"`
